# Commit Message Preferences

When the user asks for a commit message, suggests committing changes, or asks to review a commit message:

- Write commit messages in English.
- Prefer concise Conventional Commit style when it fits, for example `fix: restore email signature image`.
- If the user explicitly asks for another language or format in the current turn, follow that explicit request.
